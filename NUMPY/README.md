# NumPy Practice Notebook

A hands-on, example-driven walkthrough of NumPy — from array basics to broadcasting, linear algebra, random sampling, vectorization, and image processing with SciPy. Built while learning the library in depth, and shared here in case it helps anyone else picking it up.

## What's inside

| Section | Topics |
|---|---|
| Array Creation & Dimensions | `np.array()`, `ndim`, `ndmin`, `np.empty()`, `np.arange()` |
| Indexing & Slicing | 1D/2D/3D slicing, boolean indexing, `np.eye()` |
| Reshaping, Resizing, Stacking & Splitting | `.reshape()`, `.resize()`, `np.stack()`, `np.split()`, `np.vsplit()`, `np.hsplit()`, `np.dsplit()` |
| Broadcasting | Rules + real-world examples (calorie calculation, temperature correction, image normalization, centering data) |
| Matrix Operations & Linear Algebra | Matrix multiplication, inner/outer/cross products, determinant, inverse, eigenvalues |
| Random Sampling & Distributions | `randint`, normal, binomial, Poisson, uniform — with visualizations |
| Descriptive Statistics, Vectorization & Performance | Mean/std/var, `np.vectorize()`, loop vs. vectorized benchmarks |
| Sparse Matrices | CSR format with SciPy |
| Image Processing | Loading, cropping, flipping, Gaussian blur, sharpening with SciPy & scikit-image |

## Running it

```bash
pip install -r requirements.txt
jupyter notebook numpyPrac.ipynb
```

**Note:** two cells reference local image files that aren't generated by the code itself — `chart.webp` (used in the Broadcasting section) and `racoon.png` (used throughout Image Processing). Both need to sit in the same folder as the notebook for those cells to run or render correctly.
